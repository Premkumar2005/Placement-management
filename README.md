# Student Placement Management System (PlacementSync)

PlacementSync is a full-stack platform designed to streamline and automate university placement cell operations. It connects Students, Placement Officers (Admins), and Alumni in a unified ecosystem.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** React 19 (via Vite)
- **Routing:** React Router v7
- **State Management:** Zustand
- **Data Fetching:** TanStack React Query v5 & Axios
- **Styling:** TailwindCSS & Custom Vanilla CSS
- **Icons & Animations:** Lucide React & GSAP (GreenSock Animation Platform)

### Backend
- **Runtime Environment:** Node.js
- **Web Framework:** Express.js
- **Database:** MongoDB (via Mongoose ODM)
- **Authentication:** JSON Web Tokens (JWT) & HTTP-Only Cookies
- **Encryption:** Bcrypt.js (Password Hashing)
- **Services:** Nodemailer (Email Alerts) & Node-Cron (Automated Tasks)
